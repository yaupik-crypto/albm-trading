# AY100

A portfolio of small, single-purpose tools. One shared backend, many thin front-ends.

- `docs/` — decision records (architecture, cost, platform analysis, weekly radar output)
- `packages/core` — shared auth, billing, metering, LLM gateway, platform adapters (planned)
- `apps/` — one directory per tool, `ayNNN-<slug>` (planned)

Decisions live in `docs/` and `CLAUDE.md`. Read those before touching code.
